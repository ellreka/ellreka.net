## はじめに

マーダーミステリー(マダミス)の HO(ハンドアウト)を読み込むためのツールを作りました。

<https://muhov.app>

PDF や画像で配られる資料を並べて読み、マーカー・メモ・クリップで記録を残せる Web ツールです。登録なしで使えます。

![muhov の作業画面。左に資料一覧、中央に並べた 2 つの PDF、右にマーカーの一覧とメモがある。](https://assets.ellreka.net/muhov-about-screen.webp)

## マダミスとの出会い

マダミスのことは配信などで知っていましたが、自分が遊ぶものではないと思っていました。

1 年ほど前に知り合いに誘われて初めて体験しました。それから定期的に遊ぶようになり、今は主に同じグループで2-4人用の作品を遊んでいます。

## 作った理由

オンラインで遊ぶマダミスでは、HO や共通資料が PDF や画像で配られることが多いです。自分の HO、共通資料、途中で公開される追加資料と、開くファイルはどんどん増えていきます。

最初はデフォルトの PDF ビューアで開きながらメモを取っていましたが、次のような不便さを感じました。

- 複数の資料を行き来するうちにどこに何が書いてあったか分からなくなる
- 気になった箇所に印を付けてもあとから一覧で見返せない
- メモを別のアプリに取るので資料とメモが離れてしまう

正直、一般的な PDF ビューアだけではかなり体験が悪かったので、マダミスに特化したツールを作ろうと思ったのがきっかけです。

## できること

### 資料を並べて読む

PDF と画像を取り込み、タブと分割表示で並べて読めます。ドラッグ&ドロップして、好きなレイアウトで閲覧できます。

![共通資料とキャラクターの HO を左右に並べて表示している画面。](https://assets.ellreka.net/muhov-start-arrange.webp)

資料は URL からも追加できて、ココフォリア上に配置されている PDF にも対応しています。

### マーカー

PDF の文字を選択してマーカーを引けます。引いたマーカーは右の一覧にまとまり、クリックすると元の位置に戻れます。

![PDF に引いたマーカーと、右側のマーカーの一覧・メモ。](https://assets.ellreka.net/muhov-start-record.webp)

![マーカーを押して開いた、色の選択とコメントの入力欄。](https://assets.ellreka.net/muhov-markers-comment.webp)

### メモ

資料を読みながらメモを残せます。主要な Markdown 記法に対応しています。

![見出しと箇条書きで書いたメモ。](https://assets.ellreka.net/muhov-notes-write.webp)

`@` でタグを書けます。一度書いたタグは自動でサジェストされるので、登場人物や場所をタグにしておくと、限られた時間の中で素早くメモを整理しやすくなります。

### クリップ

PDF のページ内の範囲を画像として切り抜いて残せます。マップや人物相関図など、何度も見返す部分を手元に浮かせて置いておけます。

![PDF の上に重ねて表示したクリップ。拡大・縮小と不透明度の操作がある。](https://assets.ellreka.net/muhov-clips-float.webp)

### 検索

表示中の PDF 内の検索(`Ctrl/⌘+F`)と、閉じている資料も含めた横断検索(`Ctrl/⌘+K`)があります。

![「書斎」で横断検索した画面。左に資料ごとの検索結果が並び、選んだ箇所が PDF 上で強調されている。](https://assets.ellreka.net/muhov-search-cross.webp)

### タイマー・ダイス

部屋を作って 4 桁のコードを共有すると、参加者全員で同じタイマーとダイスを使えます。

開始・一時停止・リセットは全員に反映され、ダイスの結果は全員の履歴に残ります。

![共有タイマーのパネル。ダイスの種類を選ぶ欄と、振った結果の履歴がある。](https://assets.ellreka.net/muhov-timers-dice.webp)

タイマーは単体でも使えます。

<https://timer.muhov.app>

### ハンドアウト配布

主に GM 用で、PL ごとに渡す資料をまとめた ZIP ファイルを作れます。PDF を一つずつ渡す必要がなくなります。

![配布用 ZIP の作成画面。配布先ごとに渡す資料と、資料を表示するフェーズを選ぶ。](https://assets.ellreka.net/muhov-share-dialog.webp)

受け取った人は muhov に ZIP を読み込むだけで始められます。

フェーズと合言葉を設定すると、ゲームの進行に合わせて資料を段階的に開けるようにできます。まだ開けていない資料は受け取った人の画面に表示されません。

### 登録なしで使える

基本的な機能はアカウント登録なしで使え、データはブラウザ内にのみ保存されます。

ログインするとクラウドにも保存され、別の端末やブラウザで続きを開けるようになります。

## 技術構成

|  |  |
| --- | --- |
| フロントエンド | React / Vite / TanStack Router / Tailwind CSS / Base UI |
| 分割表示 | Dockview |
| PDF | EmbedPDF |
| 状態・端末への保存 | Zustand / Dexie(IndexedDB) |
| 認証 | Better Auth |
| インフラ | Cloudflare Workers / D1 / R2 |
| タイマー | Durable Objects |

## おわりに

自分で作ったので当たり前ですが、もうこれなしではマダミスをしたくないくらい便利で満足しています。

後から自分の書いたメモを HO と一緒に見返すのも楽しいです。

もしマダミスを遊ぶ機会があればぜひ試してみてください。
